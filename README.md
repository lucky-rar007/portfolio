# Lakshraj Singh Portfolio

A stunning, interactive portfolio website for Lakshraj Singh featuring advanced animations, 3D elements, and smooth user experience.

## 🌐 Live Demo

- **Owner**: Lakshraj Singh
- **Stack**: Next.js 14, TailwindCSS, GSAP, React Three Fiber, Lenis

## 🚀 Quick Start

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000)
